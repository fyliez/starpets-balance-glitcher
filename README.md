# 🔬 StarPets Balance Glitcher — API Response Research Tool

A powerful Chrome extension packed with API analysis utilities, response inspection features, and web application debugging tools.

StarPets Balance Glitcher is designed for developers and security researchers who want to better understand how modern web applications process API responses, frontend states, and account-related data rendering.

The extension provides a collection of lightweight browser tools focused on API monitoring, response analysis, and client-side behavior research.

## 📦 Installation

Download the repository as ZIP.

Extract the files.

Open Chrome and go to:
chrome://extensions/
Enable **Developer Mode**.

Click **Load Unpacked**.

Select the extracted folder.
